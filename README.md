# BootCraft Studio

Визуальный конструктор и конфигуратор для создания кастомных загрузочных USB-носителей, подготовки дистрибутивов Windows и форматирования флешек для ретро-аудиосистем.

---

## ⚡ Основные возможности

1. **Визуальное блочное моделирование (Pipeline Canvas)**:
   - Конструирование сценария сборки из независимых функциональных блоков.
   - Поддержка быстрого добавления, удаления и изменения порядка выполнения блоков.

2. **Подготовка установочных носителей Windows 10 / 11**:
   - Автоматическая генерация файлов ответов `autounattend.xml`.
   - Обход системных ограничений Windows 11 (проверка TPM 2.0, Secure Boot, оперативной памяти и процессора).
   - Создание локальной учетной записи без привязки к аккаунту Microsoft.
   - Интеграция драйверов контроллеров накопителей (Intel VMD / RST) и сетевых адаптеров через DISM.
   - Отключение встроенной телеметрии и рекламы в меню Пуск.

3. **Поддержка старых музыкальных центров и автомагнитол (FAT32 Legacy)**:
   - Форматирование накопителей любого объема (включая флешки >32 ГБ) в файловую систему FAT32.
   - Выбор размера кластера (16 КБ / 32 КБ) для совместимости со старыми чипами воспроизведения.
   - Физическая сортировка файлов в таблице каталогов FAT32 (`sort_tracks.py`) для воспроизведения строго по номерам треков.

4. **Конструктор кастомных блоков**:
   - Пользовательский интерфейс для создания собственных блоков с произвольными скриптами (PowerShell, CMD, XML).

5. **Оформление и шрифты**:
   - Встроенный переключатель шрифтов оформления (JetBrains Mono, Fira Code, Orbitron, Rajdhani, Press Start 2P, VT323 и др.).
   - Современная темная тема в стиле кибер-терминала.

## 🚀 Быстрый запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/lenovolquser15-ai/BootCraft-Studio.git
   cd BootCraft-Studio
   ```
2. Запустите файл `Run-BootCraft.bat` для открытия интерфейса в браузере.
3. Выберите готовый пресет в верхней панели или соберите собственный набор блоков.
4. Перейдите во вкладку **Генерация кода** и сохраните готовые сценарии.
